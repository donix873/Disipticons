КАК ОТКРЫТЬ TITAN X ULTRA В BLENDER 2.82.7

ВАЖНО: не выбирайте File > Open для файлов GLB или FBX.

Рекомендуемый вариант:
1. Откройте пустой Blender 2.82.7.
2. В Output Properties установите Frame Rate: 30 fps.
3. Нажмите File > Import > glTF 2.0 (.glb/.gltf).
4. Выберите TITAN_X_ULTRA_COMPAT_2_82.glb.
5. Дождитесь импорта.
6. Нажмите File > Save As и сохраните модель как обычный .blend.
7. Если робот не виден, нажмите Home или выделите объект и нажмите точку на цифровой клавиатуре.
8. Анимация подъёмника находится на кадрах 1–90. Нажмите кнопку Play в Timeline. Пробел работает при стандартной раскладке Blender.

Запасной вариант:
File > Import > FBX (.fbx) > TITAN_X_ULTRA_COMPAT_2_82.fbx

Почему исходный TITAN_X_ULTRA.blend не открывался:
он был сохранён Blender 4.3.2, а Blender 2.82.7 не умеет читать файлы новых версий.

Проверка совместимых экспортов:
- 54 mesh-объекта;
- 6 материалов;
- размер модели 0.275 x 0.245 x 0.080 м;
- анимация GLB присутствует у объекта TXU_lift_pivot.
