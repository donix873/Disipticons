# TITAN X ULTRA

Редактируемая модульная 3D-модель низкопрофильного соревновательного робота с безопасным демонстрационным подъёмником. Модель имеет индустриальный облик и не использует зооморфный дизайн. Внутри нет второго или миниатюрного робота.

## Состав

- `TITAN_X_ULTRA.blend` — собранная сцена.
- `main.py` — очистка сцены, вызов модулей, анимация и сохранение файла.
- `chassis.py` — шасси, колёса, панели и условные отсеки.
- `mechanism.py` — подъёмник, шарниры, ограничители и ключевые кадры.
- `materials.py` — материалы.
- `render_setup.py` — свет, камеры и параметры рендера.
- `reference_analysis.md` — анализ референсов и критерии сравнения.
- `optimization_report.md` — ограничения производительности.
- `qa_report.md` — независимая проверка и известные проблемы.
- `regulation_checklist.md` — что подтверждено цифровой моделью, а что требует прототипа.

## Открытие на Mac

1. Установите настольный Blender с официального сайта `blender.org`. Это не мобильное приложение.
2. Распакуйте весь архив проекта в одну папку; не вынимайте только `.blend` отдельно.
3. Готовый `TITAN_X_ULTRA.blend` сохранён облачной средой в Blender 4.3.2. Его можно сразу открыть в Blender 4.3.2 или новее через **File → Open**.
4. Blender 2.82.7 не умеет открывать файлы, сохранённые новыми версиями. В 2.82.7 откройте пустую сцену, перейдите во вкладку **Scripting**, загрузите `main.py` и нажмите **Run Script**. Генератор создаст и сохранит нативный файл для вашей установленной версии.
5. Скрипты написаны под API Blender 2.82.7, но в доступной облачной среде фактически запущены только на Blender 4.3.2. Первый запуск на целевом Mac остаётся обязательной проверкой.

## Анимация

Перейдите на кадр 1, нажмите пробел или кнопку Play. Демонстрация показывает складывание и подъём механизма. Она не доказывает грузоподъёмность, прочность и безопасность физического устройства.

## Редактирование и сборка

Объекты шасси, колёс, панелей и механизма создаются раздельно. Для полной пересборки из командной строки:

```bash
blender --background --python main.py
```

На Mac с Blender 2.82.7 можно запустить сборку и напрямую:

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python main.py
```

Команду запускайте из папки `TITAN_X_ULTRA`. Перед запуском сохраните собственные изменения в отдельной копии, потому что генератор создаёт сцену заново.

## Ограничения

- Точные приводы, аккумулятор, крепёж и проводка ещё не выбраны.
- Масса, центр тяжести, грузоподъёмность и ресурс не подтверждены.
- Совместимость `.blend` со старой версией Blender зависит от версии, которой файл был сохранён; скрипты являются главным переносимым источником.
- Для физического прототипа нужны расчёты нагрузок, деталировка, подбор серийных компонентов, изготовление и испытания.
